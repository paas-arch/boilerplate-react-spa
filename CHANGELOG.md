# Изменения шаблона веб-приложения на React

По этому файлу панель показывает «Что изменилось» и собирает промпт для ИИ-агента, который переносит обновление в код сервиса. Новые версии — сверху.

Формат версии: заголовок «## vX.Y.Z — ГГГГ-ММ-ДД», строка «Обязательное: да» (без обновления выкатка сломается) или «нет», пункты для людей, подраздел «### Для агента» с шагами переноса. Проверки и смену метки `.paas/template` панель добавляет в промпт сама.

## v0.4.3 — 2026-11-21

Обязательное: нет

- Шаги для агента у v0.4.0 дополнены: тема PaaS, удаление `Makefile` и старого генератора клиента API. Сервисы, обновлённые до v0.4.2 по прежним шагам, добирают это здесь.

### Для агента

1. Если в `src/app/styles/index.css` ещё нет шрифтов IBM Plex и цветов темы PaaS из шаблона, перенеси их и `theme-color` в `index.html`.
2. Если в сервисе остались `Makefile` или `scripts/generate-api.mjs`, удали их и возьми скрипт `api:generate` из `package.json` шаблона.

## v0.4.0 — 2026-11-19

Обязательное: нет

- Пример с заметками убран. Вместо него стартовая страница: промпт для ИИ-агента с примерами и кнопкой копирования, шаги до раскатки, что агент найдёт в репозитории, слои FSD.
- Инструкции для агента — в `AGENTS.md`, их читает любой агент; `CLAUDE.md` ссылается на него. В инструкциях появились правила «сначала уточни задачу» и «не раздувай».
- Скилы `feature-sliced-design`, `shadcn`, `frontend-design` и `webapp-testing` лежат в `.agents/skills` и `.claude/skills`.
- `yarn lint` проверяет структуру FSD линтером Steiger. `yarn verify` запускает всё, что проверяет CI; `Makefile` убран.
- Новые компоненты в `src/shared/ui`: Dialog, DropdownMenu, Field, Select, Separator, Skeleton, Sonner, Table, Toggle, ToggleGroup. Вместо `src/shared/lib` — пакет `cn`.
- Цвета и шрифты темы из дизайна PaaS, зависимости обновлены, TypeScript 6.0.

### Для агента

1. Перенеси из шаблона `AGENTS.md`, `CLAUDE.md` и скилы в `.agents/skills` и `.claude/skills`; правила, которые сервис дописал сам, сохрани.
2. Перенеси из шаблона `eslint.config.js` (исключения `.agents` и `.claude`), `.prettierignore`, `steiger.config.ts` и скрипты `lint`, `verify` в `package.json`.
3. Перенеси новые компоненты из `src/shared/ui` шаблона, если их нет; свои страницы сервиса не заменяй стартовой страницей шаблона.
4. Замени импорты `src/shared/lib` на пакет `cn`, как в шаблоне.
5. Обнови зависимости по `package.json` шаблона, затем `yarn install`.
6. Перенеси тему PaaS: шрифты и цвета в `src/app/styles/index.css` и `theme-color` в `index.html`, как в шаблоне. Свои цвета, которые сервис добавил сам, сохрани.
7. Удали `Makefile` и `scripts/generate-api.mjs`: проверки теперь запускает `yarn verify`, а клиент API генерирует скрипт `api:generate` с `openapi-typescript`, как в `package.json` шаблона.
8. Сверь скрипты `package.json` со скриптами шаблона: лишние из прошлой версии (`preview`, `test:watch`, `lint:fix`) убери, если сервис ими не пользуется.
9. В `AGENTS.md` замени описание стартовой страницы на описание того, что сейчас есть в `src/pages` сервиса.
