# react-web

Веб-приложение на React, созданное из шаблона `react-web` панели [paas](https://github.com/paas-arch/paas). Панель собирает его и выкатывает на сервер рядом с бэкендом проекта при каждом пуше в `main`.

Сейчас в приложении одна страница-заглушка. Дальше его дописывает ИИ-агент (Claude Code, Codex или другой): откройте репозиторий в агенте и опишите, какие страницы нужны. Правила для агента лежат в `AGENTS.md`, скилы — в `.agents/skills` и `.claude/skills`.

## Локальный запуск

Нужны Node.js 22 и Yarn 1. Бэкенд проекта должен слушать `:8080`.

```sh
cp .env.example .env.local
yarn install
yarn dev    # http://localhost:5173
```

`yarn verify` запускает всё, что проверяет CI: линтер, форматирование, тесты и сборку.

## Чего нельзя менять

`Dockerfile`, `Caddyfile`, `.github/workflows/release.yml`, команду сборки и поле `name` в `paas.toml`: по ним панель собирает и выкатывает приложение. Полный список — в `AGENTS.md`, раздел «Договор с панелью».

## Настройки на сервере

Число копий, размер и переменные окружения задаёт `paas.toml`; пояснения — в самом файле. Адрес бэкенда (`BACKEND_URL`) на сервере задаёт панель, приложение слушает порт 8080.

## Обновление скилов

```sh
npx skills update
```
